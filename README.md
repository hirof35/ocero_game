Python Othello AIPythonの標準GUIライブラリ tkinter を用いて開発された、シンプルながら強力なAIを搭載したオセロゲームです。初心者から上級者まで楽しめる難易度設定と、学習に便利な「待った」機能を備えています。✨ 特徴3段階のAI難易度:Easy: ランダムに着手します。Normal: 角（隅）を優先的に狙うアルゴリズムです。Hard: 評価表（重み付け行列）に基づき、盤面の有利な位置を戦略的に判断します。Undo（待った）機能: 直前の局面に戻して戦略を練り直すことができます。ガイド表示: 次に石を置ける場所がドットで強調表示され、初心者でもスムーズにプレイ可能です。レスポンシブなスコア表示: リアルタイムで黒と白の石の数を集計し、UIに反映します。🛠 技術的なポイントビットマップ評価法: WEIGHTS 配列により、角の死守や「X打ち」の回避など、伝統的なオセロ戦略をAIに組み込んでいます。再帰的探索の基礎: 石を挟めるかどうかのチェックには、8方向へのベクトルスキャンアルゴリズムを採用しています。非同期処理: root.after を使用することで、AIの思考時間を擬似的に作り出し、GUIのフリーズを防いで自然な対戦フィールを実現しています。🚀 実行方法Pythonがインストールされている環境であれば、追加のライブラリなしで動作します。Bash# リポジトリをクローン
git clone https://github.com/YOUR_USERNAME/python-othello.git

# ディレクトリに移動
cd python-othello

# 実行
python othello.py
